# 3.4.1 Product Backlog (User Stories)

## Overview

Functional Product Backlog for the Disaster Preparedness Training and Simulation System (San Agustin pilot). Updated **2026-08-12** to match production capabilities.

## Status Definitions

| Status | Meaning |
|--------|---------|
| ✅ Completed | Implemented and available |
| 🚧 In Progress | Active development |
| 📋 Planned | Accepted for later sprints |

## Priority Levels

- **P1** Critical (MVP) · **P2** High · **P3** Medium · **P4** Low

### MODULE 1: Authentication & User Management

- **F1**: User Registration System — ✅ Completed  
  Participant self-registration · Admin account creation · Email verification

- **F2**: Multi-Role Authentication — ✅ Completed  
  Participant / admin portals · OTP / centralized login · Super Admin

- **F2-R**: Role Model Refinement — ✅ Completed  
  Admin (full) · Lead Trainer (Full Operations) · Assistant Trainer (`LGU_TRAINER`, personnel/roster only) · Evaluator (evaluation + attendance) · Staff (roster) · Participant portal · Viewer retired from assignable UI

- **F10**: User Profile Management — ✅ Completed  
  Profile edit · Picture · Security / barangay fields · Position management
